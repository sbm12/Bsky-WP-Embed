# Bsky-WP-Embed
Wordpress plugin to enable Bluesky post embedding in Wordpress

USAGE:
Install it as a plugin in your Wordpress site (I'll eventually get it into the WP repository, but for now just save the php file, zip it, upload it manually).
Activate it.
Add Blusky posts to your site with the following syntax:
[bsky]PostURL[/bsky] - Will embed using the default layout/UX for that user

[bsky color='light|dark']URL[/bsky] - Will embed with you forcing the color scheme to either light or dark (pick one)
